# 📊 Data Analysis & Visualization

A comprehensive repository demonstrating **data analysis and visualization** techniques using **NumPy**, **Pandas**, **Matplotlib**, **Seaborn**, and **Plotly**.  
This repo includes cheat sheets, hands-on notebooks, and a capstone project to help you explore, analyze, and visualize data effectively.

---

## 🧠 What You’ll Learn

### 🔹 NumPy
Learn the foundation of numerical computing in Python.  
- Arrays and Vectorized Computation  
- Array Indexing and Operations  
- Broadcasting and Mathematical Functions  
📂 Files: `01_Arrays.ipynb` → `04_Exercise.ipynb`  
📘 Notes: `NumPy-Cheat-Sheet.pdf`

---

### 🔹 Pandas
Master data manipulation and analysis for real-world datasets.  
- Series and DataFrames  
- Handling Missing Data  
- GroupBy, Aggregation, and Pivot Tables  
- Data Operations and Cleaning  
📂 Files: `01_Series.ipynb` → `07_Operations.ipynb`  
📘 Notes: `Pandas-Cheat-Sheet.pdf`

---

### 🔹 Matplotlib & Seaborn
Visualize insights through powerful charts and plots.  
- Line, Bar, and Pie Charts  
- Distribution and Categorical Plots  
- Matrix and Regression Plots  
- Interactive Visuals using Plotly and Cufflinks  
📂 Files: `01_Matplotlib.ipynb` → `07_IPL_Capstone_Project.ipynb`  
📘 Notes: `matplotlib-cheat-sheet.pdf`

---

## ⚙️ Tech Stack
- **Python 3**

- **NumPy**, **Pandas**, **Matplotlib**, **Seaborn**, **Plotly**, **Cufflinks**
